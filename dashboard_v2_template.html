  2. 更新机制：每日 09:15（Asia/Shanghai）由 GitHub Actions 自动抓取气象与价格后重算本页，并重新生成三角色行动清单。
  3. 养殖位置：{{SITE_NAME}}，{{SITE_ADDR}}，坐标 {{LAT}}°N / {{LON}}°E（{{COORD_SOURCE}}）。
  4. 气象数据：主源 Open-Meteo（每日一次），校验源高德天气 API（中国气象局数据）；两者同日气温偏差超过阈值时以页面标注提示。
  5. 出塘价（塘口价）：养殖户在塘边卖给鱼中/收购商的价格，不含运输、损耗与市场加价。来源为公众号/视频号人工核校，非自动爬取。
  6. 批发价：农业农村部「全国水产品批发市场价格」接口（AES 解密）统货价，元/公斤 ÷ 2 折算元/斤。
  7. 规格划分：鳜鱼标鳜约 0.8~1.5 斤，另有小鳜/中鳜按成数论价；鲈鱼按两/斤计（9 两 = 450g，1 斤 = 500g）。不同来源规格口径不同，勿跨源相减。
  8. 行动清单来源：「今日行动清单」由规则引擎基于当日气象、批发价环比、病害周期与塘口价快照自动生成，属决策辅助，不构成养殖与交易决策依据。
  9. 数据边界：水质风险为「由气象推导」的风险提示，非实测传感器数据；接入实测探头前请勿作为调水的唯一依据。
